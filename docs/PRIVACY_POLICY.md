# Productivity Pro Privacy Policy

**Last updated: September 3, 2026**

Productivity Pro is designed to help users create and manage personal tasks and reminders.

## Information we collect

The current version does not require an account and does not intentionally collect or transmit personal information to a developer-operated server. Task titles, notes, completion state, and reminder times are stored locally on the user's Android device.

## Notifications

The app may request Android notification permission so it can show task reminders. Notification scheduling is performed on the device.

## Data sharing

The current version does not sell, rent, or share user task data with third parties.

## Data security

Because task data is stored locally, users should keep their Android device protected with an appropriate device lock and current Android security updates.

## Children's privacy

The current version is not designed to collect personal information from children. No account or online profile is required.

## Changes to this policy

If the app adds accounts, analytics, advertising, cloud synchronization, or other data collection, this policy will be updated before those features are used in production.

## Contact

For privacy questions, use the developer contact email published on the Google Play Store listing.
